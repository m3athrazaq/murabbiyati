# مربّيتي

مؤقت رعاية الطفل: تغيير، رضاعة، نوم، وأحداث أخرى. يعمل دون إنترنت، ويتبادل السجل مع الحضانة بملف CSV.

- **ملفات التطبيق:** `index.html` والملفات المجاورة له (تعمل كما هي من GitHub Pages).
- **نسخة الآيفون:** مجلد `native/` يحوّل الملفات نفسها إلى تطبيق iOS. كل تعديل يُرفع إلى `main` يبني ملف IPA تلقائيًا على GitHub Actions، وينشره في Releases.
- **آخر ملف IPA:** https://github.com/m3athrazaq/murabbiyati/releases/latest/download/murabbiyati.ipa — يُثبّت عبر SideStore أو Sideloadly بحساب Apple عادي، ويحتاج تجديدًا كل 7 أيام.
